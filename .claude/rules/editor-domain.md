# Editor domain

Loaded when a domain module under the actors feature's editor is read — pure logic with no framework, no React, no rendering. Each line is the rule; the full account of every line is in the feature's `HISTORY.md` beside `CLAUDE.md`.

- **At least one of each — and what that does NOT guarantee** — The guarantee is that the block EXISTS IN THE TREE, not that a visitor sees it, and that hole is accepted rather than overlooked. → `apps/hub/src/features/actors/HISTORY.md`, section "At least one of each — and what that does NOT guarantee"
- **The players (2026-08-19) — and a name that was taken back** — `player` and `jukebox` split from `embed` by LICENSING, not mechanism: only a chrome with somewhere to SHOW a video may offer a video pane. → `apps/hub/src/features/actors/HISTORY.md`, section "The players (2026-08-19) — and a name that was taken back"
- **A container is its SPACES, and there are no spans** — `columns` and `span` are gone and nothing replaced them. → `apps/hub/src/features/actors/HISTORY.md`, section "A container is its SPACES, and there are no spans"
- **A place can be a column — `addToPlace`** — A place holds one child, so a column is a `stack`, and there is no second mechanism for it. → `apps/hub/src/features/actors/HISTORY.md`, section "A place can be a column — `addToPlace`"
- **A place may be wider than its neighbours — `weights`** — Absent means uniform, and it reaches uniform through a CSS fallback rather than through a branch — one that has to be re-armed explicitly, because CSS custom properties INHERIT. → `apps/hub/src/features/actors/HISTORY.md`, section "A place may be wider than its neighbours — `weights`"
- **Adding a mode or a kind — what is guarded, and what is not** — Those lookups are `Map`s rather than records because of a fault, not a style rule. → `apps/hub/src/features/actors/HISTORY.md`, section "Adding a mode or a kind — what is guarded, and what is not"
- **What a template ships, and what a title and a description mean** — A template ships structure, never prose. → `apps/hub/src/features/actors/HISTORY.md`, section "What a template ships, and what a title and a description mean"
- **The editor composes blocks, and the shim converts what is already stored** — The whole page is ONE form field, held by one `useController`, and that is forced rather than preferred. → `apps/hub/src/features/actors/HISTORY.md`, section "The editor composes blocks, and the shim converts what is already stored"
- **Dragging (2026-08-18; inspector corrected 2026-09-01)** — The two halves of a drag live in `domain/`, not in a component. → `apps/hub/src/features/actors/HISTORY.md`, section "Dragging (2026-08-18; inspector corrected 2026-09-01)"
- **Era looks (2026-08-28) — five OPTIONS, and not one new skin** — Each look wears its release's own mark as an avatar, and is public and listed (2026-08-29). → `apps/hub/src/features/actors/HISTORY.md`, section "Era looks (2026-08-28) — five OPTIONS, and not one new skin"
- **A page has a document (2026-08-27)** — A `theme` that is present but not a plain object — `[]`, a string, a number — is refused as its own `envelope` problem too (2026-08-28), found by a whole-branch review. → `apps/hub/src/features/actors/HISTORY.md`, section "A page has a document (2026-08-27)"
- **The section preview's face is not the control card** — `card_size` is in the schema, in no popup, and read by no page. → `apps/hub/src/features/actors/HISTORY.md`, section "The section preview's face is not the control card"
- **The page's own background picture (Phase D)** — It renders as a second `background-image` layer on `body`, above `var(--field)` — never at `:root`, because `body` paints its own opaque background over `:root`'s. → `apps/hub/src/features/actors/HISTORY.md`, section "The page's own background picture (Phase D)"
- **The architecture pass (2026-08-27) — what moved and what deliberately did not** — CSS emission lives in `presentation/theme-css.ts`, never in `domain/`; `domain/actor-theme.ts` keeps only the vocabulary. → `apps/hub/src/features/actors/HISTORY.md`, section "The architecture pass (2026-08-27) — what moved and what deliberately did not"
- **`list` — the divided list (2026-08-27)** — It is an ARRANGEMENT and decides nothing about its children. → `apps/hub/src/features/actors/HISTORY.md`, section "`list` — the divided list (2026-08-27)"
- **Closing the pastiche gaps (2026-08-27) — five new OPTIONS** — Three keys on a block's style bag — `chrome` (`card`/`bare`), `heading` (`plain`/`bar`/`gradient`), `text_align` — plus `font` and `spacing` on the page theme; absence must mean exactly what the page did before the key existed. → `apps/hub/src/features/actors/HISTORY.md`, section "Closing the pastiche gaps (2026-08-27) — five new OPTIONS"
- **Closing the REST of the pastiche gaps (2026-08-27) — four more options** — `image_fit`'s default lives at `:root`; absence emits NOTHING rather than `cover`, so an unstyled block never overwrites an enclosing section's `contain`. → `apps/hub/src/features/actors/HISTORY.md`, section "Closing the REST of the pastiche gaps (2026-08-27) — four more options"
- **A block may hide its own title as a label (2026-08-29)** — `hidden` NARROWS what the enclosing mode already decided; it never WIDENS it. → `apps/hub/src/features/actors/HISTORY.md`, section "A block may hide its own title as a label (2026-08-29)"
- **A portrait's size, apart from the text beside it (2026-08-30)** — It is read directly off the LEAF's own `style.portrait`, and that is a deliberate difference from `image_fit`, not an oversight. → `apps/hub/src/features/actors/HISTORY.md`, section "A portrait's size, apart from the text beside it (2026-08-30)"

- **The Properties panel replaces the recursive inspector (2026-09-04)** — Exactly two tabs, fixed per selection kind, never a variable number. → `apps/hub/src/features/actors/HISTORY.md`, section "The Properties panel replaces the recursive inspector (2026-09-04)"
