What changed

Sign-in lost its centred-hero composition and inherited the signed-in shell: header bar with the wordmark, left-aligned page title, content in the same 620px column, identical cards. The gradient is the gentler one from /me rather than the dramatic one. Both themes now use one layout — the only difference between them is the token block.

Star field removed. Gradient plus one cloud layer is the whole atmosphere now. It is simpler, faster, and has no filter maths left to get wrong.
