How it is built

The cloud texture is real fractal noise — five octaves of value noise, the same thing the SVG filter was producing — rendered once into two offscreen tiles. Animation is those tiles drifting past each other at different speeds, so no noise is recalculated per frame. That is why it moves without costing much.
