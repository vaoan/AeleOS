Notes

The canvas is sized in device pixels and redrawn on resize, so it stays sharp and never becomes the 300×150 square the SVG was. Motion is a slow drift; with prefers-reduced-motion set it renders one static frame instead of animating, rather than disappearing.

In the real app this is position: fixed; inset: 0 over the whole window like moonfest, so it stays put while the page scrolls, and the toggle lives in the user menu and persists.
